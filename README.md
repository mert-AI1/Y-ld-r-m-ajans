# Yıldırım Ajans

Mert Yıldırım için hazırlanmış, GitHub Pages ile yayınlanmaya uygun statik ajans sitesi.

## Dosyalar
- `index.html` — sayfanın yapısı
- `style.css` — tasarım ve responsive görünüm
- `script.js` — menü, animasyonlar ve iletişim formu

## GitHub Pages
1. Bu üç dosyayı GitHub repository'nize yükleyin.
2. Repository > Settings > Pages bölümüne girin.
3. Source olarak `Deploy from a branch` seçin.
4. `main` branch ve `/root` klasörünü seçip kaydedin.
5. GitHub size sitenizin adresini verecektir.

## Kişiselleştirme
`index.html` içindeki telefon, e-posta ve sosyal medya bağlantılarını kendi bilgilerinizle değiştirin.
